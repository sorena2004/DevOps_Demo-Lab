# End-to-End DevOps Microservices Platform

A local Kubernetes-based DevOps project demonstrating:

- Node.js Microservices
- Docker
- Kubernetes
- Minikube
- GitHub Actions
- CI/CD
- Ingress
- HPA
- Prometheus
- Grafana
- kube-state-metrics
- cAdvisor
- Alertmanager
- Monitoring
- Kubernetes Rollback
- Kubernetes Backup
